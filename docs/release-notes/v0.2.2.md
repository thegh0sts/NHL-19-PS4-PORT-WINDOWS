A crash fix, and a new launcher window to try.

**Game**
- Fixed a crash when the game's watchdog (HangMonitor) notices a slow thread, for example while
  the shader cache is built on a first run: it read that thread's stack at the wrong address,
  because the port didn't report where thread stacks are. The real addresses are now reported.
  First found in the NHL 21 port, which shares this code

**New launcher (testing)**
- `bin\NHL19Launcher.exe`: a new launcher window made with SDL3 and Dear ImGui, like the in-game
  menu. It checks the game folder you choose (serial, update, or a separate update folder to
  merge), has the settings in four tabs, and works with a mouse, keyboard or controller
- It shares its settings with `NHL19.exe`, and Play starts `NHL19.exe --play`, so the game starts
  exactly as before. `NHL19.exe` stays the main launcher while the new one is tested

**Linux (test builds)**
- NHL 19 is now also built for Linux, as an AppImage and a tar.gz, published as separate
  pre-releases. They haven't been run by the developer yet: reports are welcome

**Known issues**
- Main menu hub tiles are still empty (EAWebKit isn't loaded yet)
- A slight jitter at the bottom of the jerseys in team select
- Modes other than Play Now and NHL Threes are lightly tested; one local player only; no online play

**Installing:** unzip into a new folder (or over v0.2.1) and run `NHL19.exe`. Your settings and saves
in `%LOCALAPPDATA%\NHL19Native` carry over.

This release contains no game files: you need your own PS4 copy of NHL 19 (CUSA11126, update 1.60).
