A fix for crashes and hangs during play and at start-up.

**Game**
- Fixed a bug in how the port moves the game's short-lived stack data out of Windows' way: in a
  few functions it moved only some of the instructions that use a given value, so one of them
  read the value from the wrong place. In NHL 20 and NHL 21 this crashed the game during play
  ("Guest fault … (thread SimThread)"). In NHL 19 it can also leave the game waiting forever,
  for example on the spinner after the EA SPORTS intro. Instructions that use the same value now
  always move together, or all stay where they are

**Known issues**
- Main menu hub tiles are still empty (EAWebKit isn't loaded yet)
- A slight jitter at the bottom of the jerseys in team select
- Integrated graphics (such as the Radeon Vega in Ryzen 5600G/5700G) are untested. If you use
  one, set the graphics memory in the BIOS ("UMA Frame Buffer Size") to 2 GB or more
- Modes other than Play Now and NHL Threes are lightly tested; one local player only; no online play

**Installing:** unzip into a new folder (or over v0.2.2) and run `NHL19.exe`. Your settings and saves
in `%LOCALAPPDATA%\NHL19Native` carry over.

This release contains no game files: you need your own PS4 copy of NHL 19 (CUSA11126, update 1.60).
